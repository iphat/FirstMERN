# To combine frontend into backend - 

1- Frontend - npm run build

2- a dist folder is created in Frontend folder

3- From the "dist" folder of frontend, Copy the "assets" folder and "index.html" file.

4- Then create a public folder in backend and paste both "dist" folder and "index.html" file into this public folder.

4- Remove all 3 files from dist folder

5- It must be necessary that the apis end points should be same in both frontend and backend.

6- Now frontend merged in backend and now check the backend apis.
